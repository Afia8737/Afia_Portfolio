# Afia Ibnat — Portfolio

A responsive, dark-themed portfolio built with Next.js and React. It presents Afia's web development work, academic computer vision projects, technical skills, internship experience, and contact links.

## Run locally

Requirements: Node.js 18.18+ (Node.js 20+ recommended).

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Build for production

```bash
npm run build
npm start
```

## Customize

- `app/page.js` — homepage content, project descriptions, skills, and repository links.
- `app/globals.css` — responsive layout and visual styling.
- `public/afia-profile.jpg` — supplied profile portrait.
- `public/Afia-Ibnat-CV.pdf` — CV download asset.

The three web project cards link to the public GitHub repositories. Academic/concept project artwork is CSS-based illustrative artwork, not a claim that it is a screenshot of the underlying project. Replace it with original screenshots or research figures when available.
